# DRIM — детерминированное обезличивание с сохранением ссылочной целостности

Референсная реализация метода из статьи «Метод детерминированного обезличивания
данных в реляционных СУБД с сохранением ссылочной целостности» (Сыропятов Е. М., 2026).

## Архитектура

Пакет построен четырьмя слоями с однонаправленными зависимостями:

```
ff1.py      NIST SP 800-38G: формат-сохраняющее шифрование (AES, сеть Фейстеля)
   ↑
stream.py   PrfStream: поток байтов из корня h0 + равномерный индекс с отбраковкой
   ↑
pools.py    пулы замен: фамилии, имена, отчества, домены; алфавиты e-mail
   ↑
rules.py    типизированные правила (email, fio, login, phone, int_id, date)
   ↑
engine.py   DRIM: канонизация → HMAC-SHA256 (доменное разделение) → правило → результат
```

Каждое правило реализует единый интерфейс: `canonical(value)` — приведение значения
к канонической форме, `mask(value, prf)` — порождение замены из псевдослучайного
потока. Новые типы данных добаваются новым классом правила без изменений в других
слоях. Твик FF1 вычисляется из ключа отдельно для phone и int_id, поэтому замены
типов статистически независимы.

## Состав пакета

| Файл | Назначение |
|---|---|
| `drim/ff1.py` | FF1 по NIST SP 800-38G (Алгоритмы 7–8), radix ≤ 36, AES-128/192/256 |
| `drim/stream.py` | Псевдослучайный поток из корня + равномерный выбор без modulo bias |
| `drim/pools.py` | Пулы замен и алфавиты |
| `drim/rules.py` | Типизированные правила замены |
| `drim/engine.py` | Движок DRIM (mask, mask_row) |
| `test_ff1.py` | 8 официальных векторов NIST + биективность на 90 000 значений + валидация параметров |
| `test_drim.py` | 20 проверок: детерминизм, форматы, NULL, межтабличная консистентность, инъективность, birthday-модель, χ² |
| `benchmark.py` | Эксперимент 1–2 статьи: DRIM vs словарь vs случайная замена |
| `exp3_utility.py` | Эксперимент 3: метрики полезности данных (n = 100 000) |
| `requirements.txt` | Зависимости |

## Минимальный пример

```python
from drim import DRIM

m = DRIM(b"your-256-bit-secret-key-here-32b!!")
print(m.mask("Иванов Пётр Сергеевич", "fio"))      # Смирнов Артём Викторович
print(m.mask("ivanov@example.com", "email"))        # k3x9q1w@mail.ru (первый символ — буква)
print(m.mask("123456789", "int_id"))                # 482913705 (биекция)
print(m.mask("+7 912 345-67-89", "phone"))          # +7 (615) 902-48-13
print(m.mask("1990-05-12", "date"))                 # 1990-03-28 (тот же год)
```

## Гарантии (проверяются тестами)

- **Детерминизм**: равные значения → равные замены во всех таблицах ⇒ внешние
  и естественные ключи сохраняются без анализа схемы.
- **Биективность ID/телефонов**: FF1 с фиксированным твиком — перестановка домена.
- **Постоянство памяти**: единственное состояние — 32-байтный ключ.
- **Отсутствие словаря деанонимизации**: таблица соответствий не порождается.
- **Равномерность пулов**: отбраковка (χ² = 3,4 < 16,92 при df = 9).
- **Согласованность рода**: женские/мужские отчества согласуются с именами.

## Ограничения

- Детерминизм сохраняет частотный профиль значений (частотная утечка) — см. разд. 7 статьи.
- FF1 на чистом Python: ≈ 4,2 тыс. строк/с; для продакшена — перенос на Go/Rust.
- Пулы фиксированы в коде; для продакшена вынести в конфигурацию.
